最终方案确认

三个模块并行推进，下面是完整设计大纲

模块一：API 响应增强（方案 A）

端点 新增字段 说明
/api/dataset/{name} _ai_context 摘要、趋势、top tasks、共现数据集
/api/paper/{id} _ai_context 数据集概览、task 分布、data type 分布
/api/query _ai_context 结果摘要、建议的后续查询
/api/datasets _ai_context top 10 高频数据集预览

模块二：数据集共现图谱

新端点：

  • GET /api/dataset/{name}/related?top_n=20 — 共现数据集 + co_usage_count
  • GET /api/dataset/{name}/trends — 按年/月的使用趋势

前端：新页面 /dataset/{name}/graph，D3.js 力导向图

节点：中心 = 目标数据集（大节点），周围 = 共现数据集（大小按 co_usage 缩放）

边：粗细 = 共现论文数，hover 显示详细数字

模块三：数据集详情页增强

Chart.js 两个轻量图表，嵌入现有 dataset.html：

  • 年度趋势折线图 — X=年份, Y=使用该数据集的论文数
  • Task 分布饼图/环形图 — 该数据集被哪些 task 使用

技术栈

  • 后端：Flask + SQLite（不动架构，只加端点和响应字段）
  • 图谱：D3.js v7（~30KB gzip，力导向图就它最成熟）
  • 图表：Chart.js（~30KB gzip，够用且轻量）
  • 全部通过 CDN 加载，不增加构建负担

AI Agent 访问路径总结

1. 发现 API — 读本地 llms.txt 或 api-config.json

2. 验证连接 — GET /chatpd/api/data-status

3. 搜索/查询 — GET /chatpd/api/query?q=... 或 /api/datasets?search=...

4. 深度分析 — /api/dataset/{name} 获取 _ai_context（趋势、共现、task分布，一次拿到）

5. 网络关系 — /api/dataset/{name}/related 获取共现图谱数据
